# Technical Product Website Template

A Docusaurus-based documentation site template with two doc sections — **Getting Started** and **Design Docs** — deployed to GitHub Pages.

## Run locally

**Prerequisites:** Node.js >= 20

```bash
npm install
npm start
```

The site opens at `http://localhost:3000/technical-product-website-template/`. Changes to `.mdx` and `.tsx` files hot-reload automatically.

To preview the production build:

```bash
npm run build
npm run serve
```

## Deploy to GitHub Pages

The site deploys from your local machine directly to the `gh-pages` branch.

```bash
GIT_USER=<your-github-username> npm run deploy
```

This builds the site and force-pushes the output to `gh-pages`. The live URL updates within a minute.

> Make sure `organizationName`, `projectName`, and `url` in `docusaurus.config.ts` match your GitHub username and repository name before deploying.

## Add a new page

Pages live inside the two `docs` directories. Pick the section where the page belongs:

| Section | Directory |
|---|---|
| Getting Started | `docs-getting-started/` |
| Design Docs | `docs/` |

Create an `.mdx` file with a frontmatter block at the top:

```mdx
---
sidebar_position: 2
---

# My New Page

Content goes here.
```

`sidebar_position` controls the order within the sidebar — lower numbers appear first. Both sidebars are autogenerated, so the file appears automatically without editing any sidebar config.

## Add a new page group

A page group is a folder that groups related pages under a collapsible sidebar section.

1. Create a subfolder inside the target docs directory, e.g. `docs-getting-started/My-Group/`.
2. Add an `index.mdx` as the group's landing page (optional but recommended).
3. Add a `_category_.json` to control the group label and order:

```json
{
  "label": "My Group",
  "position": 3,
  "link": {
    "type": "generated-index"
  }
}
```

4. Add `.mdx` files inside the folder — they appear as children of the group in the sidebar.

Example structure:

```
docs-getting-started/
  My-Group/
    _category_.json
    index.mdx
    setup.mdx
    troubleshooting.mdx
```

## Update configuration

All site-wide settings live in [docusaurus.config.ts](docusaurus.config.ts).

| Setting | Where to change |
|---|---|
| Site title and tagline | `config.title` / `config.tagline` |
| Logo and favicon | `config.favicon`, `themeConfig.navbar.logo` |
| GitHub Pages URL | `config.url`, `config.baseUrl`, `config.organizationName`, `config.projectName` |
| Navbar links | `themeConfig.navbar.items` |
| Footer links | `themeConfig.footer.links` |
| Dark/light mode | `themeConfig.colorMode` |
| Syntax highlight theme | `themeConfig.prism` |
| Add a new docs section | Add an entry to `config.plugins` and create a matching sidebar file |

To add a second additional docs section (beyond the two already present), copy the plugin entry for `docs-getting-started` and update `id`, `path`, `routeBasePath`, and `sidebarPath` to point at the new directory and sidebar file.
